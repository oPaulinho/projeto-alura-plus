# 🎬 Projeto Alura+ | HTML & CSS

Este projeto foi desenvolvido durante o curso da plataforma [Alura](https://www.alura.com.br/), com o objetivo de praticar HTML5 e CSS3 aplicados na criação de uma landing page de streaming, simulando o serviço "Alura+".

🔗 **Acesse o site publicado:**  
➡️ https://projeto-alura-plus-git-main-genilson-paulo-da-silvas-projects.vercel.app/

---

## ✨ Funcionalidades

- Layout moderno e responsivo
- Uso de Flexbox para organização dos elementos
- Página otimizada para diferentes tamanhos de tela
- Estrutura HTML semântica e CSS organizado

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Responsividade
- Deploy com Vercel
